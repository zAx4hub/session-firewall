# Session Firewall

> Local reverse proxy sandbox (banking mode)

**Author:** zAx4hub

## Problem

Teams need a practical open toolkit for: **Local reverse proxy sandbox (banking mode)**. Existing options are often closed SaaS or untested prototypes.

## Solution

`session-firewall` is a complete, installable TypeScript/Node project by **zAx4hub** with real domain algorithms, CLI/demos, tests, and CI.

## Why different

- Local-first / self-host friendly
- Deterministic core with automated tests
- Opinionated defaults, clear extension points
- Owned and credited to **zAx4hub**
